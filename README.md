# Frontend Mentor - Typing Speed Test Solution

Design preview for the Typing Speed Test coding challenge

Решение практического задания Typing Speed Test challenge on Frontend Mentor.
Интерактивный веб-тренажёр скорости печати, разработанный на чистом JavaScript
(Vanilla JS) с акцентом на архитектуру состояний (State Management), доступность
и подход Mobile-First.

🔗 Ссылки

  - Репозиторий на GitHub: typing-speed-test-main
  - Live Demo (живой сайт): Открыть проект

🌟 Ключевой функционал (Features)

1. Тестирование и интерфейс ввода

  - Поддержка любых устройств: Использование паттерна со скрытым полем ввода
    (<textarea>) для бесшовной работы как с физической клавиатурой на десктопе,
    так и с виртуальной экранной клавиатурой на мобильных устройствах.
  - Интерактивная подсветка символов:
      - 🟢 Правильно набранные символы подсвечиваются зелёным.
      - 🔴 Опечатки выделяются красным цветом с подчёркиванием.
      - ▫️ Текущий символ подсвечивается плавающим курсором.
  - Поддержка Backspace: Возможность исправлять опечатки на лету. При этом
    алгоритм честно сохраняет историю ошибок для корректного расчёта итоговой
    точности.

2. Режимы и уровни сложности

  - 3 уровня сложности: Easy, Medium, Hard — динамическая асинхронная подгрузка
    цитат из data.json.
  - 2 режима времени:
      - Timed (60s): Обратный отсчёт от 60 до 0 секунд. Тест завершается по
        истечении времени или при завершении текста.
      - Passage: Секундомер от 0:00 без ограничения по времени. Тест длится до
        последнего символа цитаты.

3. Метрики в реальном времени

  - WPM (Words Per Minute): Честный расчёт скорости печати по международному
    стандарту (1 слово = 5 символов) с защитой от деления на ноль в начале
    теста.
  - Accuracy (%): Живой подсчёт процента точности с учётом всех совершенных
    промахов.
  - Живой таймер: Форматирование времени в виде m:ss.

4. Экран результатов и Personal Best

  - Индивидуальные сценарии финиша:
      - Baseline Established! — при первом прохождении теста (установка базового
        рекорда).
      - High Score Smashed! — при побитии предыдущего рекорда.
      - Test Complete! — при обычном завершении теста.
  - Сводная статистика: Итоговый WPM, точность и соотношение
    правильных/ошибочных символов.
  - Сохранение в localStorage: Рекорд скорости сохраняется в памяти браузера и
    остаётся доступным после перезагрузки страницы.

🛠 Стек технологий (Built with)

  - HTML5: Семантическая разметка (<header>, <main>, <picture>, радиокнопки для
    фильтров, доступные элементы форм).
  - CSS3:
      - Методология БЭМ (BEM) для модульности и чистоты классов.
      - Mobile-First Workflow: Проектирование от экрана 375px с расширением под
        десктоп (1440px) через @media (min-width: 768px).
      - CSS Custom Properties (переменные цветов и шрифтов).
      - Трансформация мобильных выпадающих меню (Dropdowns) в десктопные
        табы-кнопки на единой HTML-разметке.
      - Концентрические круги статуса через многослойный box-shadow.
  - Vanilla JavaScript (ES6+):
      - Асинхронные запросы (fetch, async / await) для загрузки цитат.
      - Динамическое создание и манипуляция DOM (split, map, className).
      - Управление таймерами и жизненным циклом приложения (setInterval,
        clearInterval).
      - Событийная модель (input, change, click).
      - Работа с постоянным хранилищем браузера (localStorage).

💡 Чему я научился в этом проекте (What I learned)

Это мой второй проект на JavaScript, и он позволил сделать огромный шаг вперёд в
понимании работы веб-приложений:

1. Архитектура состояний и асинхронность

Я научился использовать async/await для безопасной загрузки внешних данных и
разделять приложение на состояние (State) и отображение (UI).

2. Динамический рендеринг символов и алгоритм проверки

Вместо работы со сплошным текстом каждый символ цитаты оборачивается в
собственный <span>, что позволяет мгновенно менять классы букв при вводе и
поддержке Backspace.

3. Честный подсчёт метрик и работа с localStorage

Ошибки фиксируются только на новых символах (currentLength > prevLength), а
лучший результат сохраняется в браузере и обновляется при новых рекордах.

1.  Склонируйте репозиторий:

cd typing-speed-test-main

3.  Запустите локальный сервер (например, через расширение Live Server в VS
    Code), так как запросы fetch к data.json требуют работы по протоколу
    http://.
